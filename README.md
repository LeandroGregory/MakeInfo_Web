Projeto: Make Info Web 

Este é um projeto de um sistema de software para uma loja de produtos de informática com as funções de:

Cadastrar,fazer a listagem e deletar dados de protutos, funcionários e clientes.
Fazer o gerenciamento de venda dos produtos.
Fazer o gerenciamento de estoque dos produtos.
Tecnologias utilizadas no projeto:

Plataforma de desenvolvimento: Java
Banco de dados: MySQL
Repositório do código: GitHub
